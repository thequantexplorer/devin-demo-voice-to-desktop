# acme-status-page

status.acme.dev. Shows current component status from `/api/status`. `/api/history` already serves 30 days of uptime rollups and past incidents, but the page doesn't render them yet.

```sh
npm install && npm start   # http://localhost:3200
npm test
```

This repo is a starter for a Devin demo. See [DEVIN_DEMO.md](DEVIN_DEMO.md) for setup and the prompt.
